# M0.2 Decision Evidence Envelope v2 — implementation authority

This supersedes v1. It wraps frozen M0.2 at `bc3a40924ca580ca6eddc4c24e32ff99ddd95330`; no eligibility, STOP, capability, output, action, or `decision_id` semantics change. `decision_id` is local deterministic content binding only.

## Closed evidence closure

The adapter captures a content-addressed blob for every byte source used in the actual branch. A blob is `{blob_sha256,media_type,byte_length,base64_bytes}`; digest/length must verify. A source manifest item is `{source_id,source_class,directness,path,blob_sha256,canonical_sha256|null,schema_identity|null}`. `directness` is `INPUT`, `HELPER`, `VALIDATOR`, `ENGINE`, `INVENTORY`, or `DENY_CONTEXT`; unknown fields deny. Raw bytes prove historical read identity; canonical parsed bytes prove semantic parsed identity. Changed JSON formatting may preserve canonical identity but changes raw identity.

For DISPATCH, capture intent; scheduler state and schema; referenced project/state schemas; every STOP and STOP inventory; task and task inventory; claimed handoff and complete matching handoff-ID inventory; assignment head and inventory; handoff binding; recursively traversed dependency/completion records; all capability records/inventory; repository root/remote/HEAD/origin-main/reachability; and all path/absence assertions. For DENY, capture the exact branch error plus the complete `_denial_context` source directories: project JSON, handoffs, stops, assignments, bindings, tasks, completions, capabilities, scheduler state, intent and inventories. Capture every imported decision-critical local module/schema: `orchestration.py`, `validate.py`, `data_integrity.py`, all schemas reached by `validate_record`, and the Python/jsonschema identities. Inventory entries are ordered by repository-relative UTF-8 path and include missing/extra/malformed names; a move is stale where path/inventory is consumed.

## Canonical form, environment, and replay

Canonical JSON is UTF-8, no BOM, duplicate-key rejection before parsing, Unicode codepoints preserved without normalization, lexicographic object keys, no whitespace, JSON booleans distinct from integers, integers only, floats/nonfinite denied, explicit null, arrays preserve semantic order, sets are sorted by canonical member bytes, paths use repository-relative `/`, timestamps are RFC3339 UTC `Z`. Empty objects/lists and absent fields are distinct. One implementation performs generation and verification.

The engine manifest is immutable at the freeze: `{freeze_commit, entries:[path,blob_sha256], python_implementation,python_version,jsonschema_version, loader, clock_adapter}`. Replay materializes blobs in an isolated verified checkout rooted at the freeze, validates origin/HEAD/origin-main identities from the manifest, imports only those materialized modules, and supplies `evaluation_time` as the clock adapter’s aware UTC instant. It never imports today’s mutable modules. A missing/corrupt blob, unavailable environment, wrong engine closure, or replay mismatch is `INVALID`.

## Strict envelope

Envelope fields are closed by `m0-2-decision-evidence-envelope.v2.schema.json`: metadata/subject `{task_id,attempt,assignment_head,handoff_head}`, repository/runtime binding, evaluation environment, source and engine manifests, canonical input, exact `raw_output` bytes/digest, normalized output, and all digests. Raw output is exactly the returned mapping bytes. Normalized output is separately derived and closed: `{decision,decision_id,task_id,reason,execution_adapter,operation}` where `operation` is null only for DENY. Unexpected raw keys are preserved but normalization fails closed. Hash `SHA256(canonical(envelope without envelope_sha256))`; all dependencies are finalized first.

Generate under common advisory Git/runtime lock: resolve/persist candidate blobs and inventories; construct manifests/input; invoke frozen engine at captured time; preserve raw output; normalize; build/hash envelope; final-resolve current authoritative bundle while lock held; deny/block on A→B change; atomically persist blobs, envelope, envelope reference and transition/idempotency evidence in SQLite; release lock.

`verify_historical` validates schema/hash/blobs/engine, reconstructs the historical isolated environment, rebuilds input, reruns at evaluation time, compares raw output, normalized output and decision ID, then returns `HISTORICALLY_VALID` or `INVALID`. Only then `verify_currentness` acquires the common lock and compares current repository/attachment, remote/origin-main/HEAD, inventories, task/attempt, assignment/handoff, project/STOP, dependency/completion, capabilities, runtime/repository generation and all direct inputs. It returns `CURRENT`, `STALE`, or `INVALID_CURRENT_STATE`. Overall values are `VALID_CURRENT`, `VALID_STALE`, `INVALID`. Historical deletion/move with intact blobs is stale, not invalid. Wrong runtime attachment is historically attestable only in its own context and `INVALID_CURRENT_STATE` for the target runtime.

## Runtime policy and retention

| Transition | historical | current DISPATCH | reuse |
| --- | --- | --- | --- |
| CLAIM, START, CONTINUE | required | required, exact task/attempt/runtime generation | only while rechecked current |
| COMPLETE | required | required; otherwise deny successful completion | same |
| REVALIDATE | required | newly generated current envelope | no old envelope |
| REPORT_BLOCKED, RECORD_EVIDENCE, REPORT_FAILURE, SAFE_YIELD | historical if referenced | not required; no new effect | evidence only |
| review/remediation/cancel/recovery/retry | no envelope authorization | n/a | n/a |

After governance block, only the evidence-only rows above are legal; they preserve observations but cannot claim current work completion. SQLite stores immutable blobs, manifests, envelope bytes, raw output, normalized output, evaluation time and event references; updates/deletes deny. Backup/export include all referenced blobs and verify restore digests. Legacy caller `receipt_digest`, arbitrary envelope IDs and `verified` flags are non-authorizing historical data only and every authorization fallback is removed.

Required tests cover all DISPATCH/DENY branches, helpers/schemas/environment mutations, clock boundary, duplicate keys/floats/Unicode/list/order, raw-vs-canonical identity, blob deletion/current source changes/moves, output shape, generation races, historical-valid/stale/invalid distinctions, wrong runtime, evidence-only governance actions, every R gate, legacy fallback denial, and byte-identical Stage 1 regression.
