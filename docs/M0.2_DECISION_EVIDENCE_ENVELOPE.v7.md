# M0.2 Decision Evidence Envelope v7 — sole implementation planning authority

V7 supersedes all prior adapter plans. Earlier versions are historical evidence only. A usable envelope requires schema, content and semantic verification; `envelope_sha256=SHA256(CJ(envelope excluding only envelope_sha256))`.

The envelope carries exactly one closed project binding (record id/version/head, `live_status`, `capital`, source artifact), STOP binding (inventory artifact/digest and ordered STOP record artifacts/statuses), dependency binding (ordered unique task/head/completion artifacts), capability binding (id/version/head/disposition/effects/artifact), Git observation, source manifest, blob set, and engine distribution. Semantic verification requires all authority artifact IDs be in source manifest and that the frozen branch has no omitted authority source.

Every FILE/engine artifact resolves to one Blob v1 record; strict base64 decode, raw length, SHA-256 and `blob_id==digest` are mandatory. DIRECTORY has only FILE members; `OTHER` is forbidden. Logical-record digests are `SHA256(CJ(record excluding its own digest field))`; byte digests are SHA-256 raw bytes. This applies to absence, inventory, source/import/validation/Git/engine/canonical-input/output and envelope records.

Git observation v1 contains historical HEAD/origin main/origin URL/ancestry operands-result and repository ID; the shim uses it exclusively. Engine distribution v2 is one immutable artifact-backed package model: every external dependency names exact version, wheel/sdist blob digest and platform/interpreter constraints. Replay uses only distribution-relative work/module paths and fixed literal environment values.

Raw output is the exact frozen DISPATCH/DENY union; base64 bytes parse to it and normalizer copies only frozen fields. Deny operation is null, dispatch operation is nonempty. V9 B0 prerequisites and non-operational events remain unchanged.
