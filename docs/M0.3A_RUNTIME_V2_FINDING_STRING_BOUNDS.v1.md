# Runtime-v2 verifier finding-string bounds

This deny-only evidence contract classifies two sibling character maxima in
`src/edgelab/runtime_v2_verifier.py` as one atomic semantic family. It does not
make a finding correct, accept an image, clear a STOP, or authorize execution.

## Artifact bound

`MAX_FINDING_ARTIFACT_CHARS` is 256 characters. The sole subject-specific
caller passes `VerificationFinding.artifact` to the nested `bounded` helper.
An artifact whose Python string length is at most 256 is returned unchanged.
For a longer artifact, the helper hashes the full original UTF-8 byte sequence
with SHA-256 and returns the first 184 characters plus `#sha256=` plus the
64-character lowercase hexadecimal digest. The result is exactly 256 Python
characters.

The accepted equation is:

`len(artifact) <= 256 OR output = artifact[:184] + '#sha256=' + sha256(artifact.encode('utf-8')).hexdigest()`

## Coordinate bound

`MAX_FINDING_COORDINATE_CHARS` is 512 characters. The sole subject-specific
caller passes `VerificationFinding.coordinate` to the same nested helper. A
coordinate whose Python string length is at most 512 is returned unchanged.
For a longer coordinate, the helper hashes the full original UTF-8 byte
sequence with SHA-256 and returns the first 440 characters plus the same
72-character suffix. The result is exactly 512 Python characters.

The accepted equation is:

`len(coordinate) <= 512 OR output = coordinate[:440] + '#sha256=' + sha256(coordinate.encode('utf-8')).hexdigest()`

## Shared machinery and exclusions

The helper comparison and generic truncating slice are shared implementation
machinery. They remain unclassified and must not be counted as either
subject-specific definition or enforcement. Each semantic constraint binds
only its raw definition, subject-specific caller, and subject-specific derived
composite. Artifact and coordinate maxima cannot be swapped or selected by
untrusted input.

The following remain outside both constraints: the 128-finding count limit,
schema traversal/default/remaining-budget meanings, diagnostic correctness,
finding uniqueness or ordering, public-verifier acceptance, closure or carrier
generation, STOP state, workflow/reviewer/decision authority, execution,
wagering, and capital authority.

Boundary evidence covers 0, maximum minus one, maximum, and maximum plus one
for both subjects. Multibyte Unicode proves that admission and slicing count
Python characters while the digest consumes the complete original UTF-8 bytes.
Adversarial evidence changes definitions, callers, subject/constants,
comparison, encoding, digest input/algorithm, suffix, slice, construction
order, predecessor shape, site membership, and census identities. Every such
mutation must fail closed.
