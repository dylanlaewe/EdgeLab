# M0.3A v7 decision-evidence integration amendment

V7 supersedes v6. [M0.3A v3](M0.3A_TRANSACTIONAL_CONTRACT.v3.md) remains the sole scheduler state-machine authority. This amendment adds only envelope verification requirements from [Envelope v4](M0.2_DECISION_EVIDENCE_ENVELOPE.v4.md); it does not rename states, alter tuple effects, or change dispatch generation.

| Existing v3 transition | Envelope requirement added | Scheduler semantics unchanged |
|---|---|---|
| claim `N0→N1` | current `VALID_CURRENT` DISPATCH for exact task/attempt/runtime/repository generation | issue claim; `+S+D+F` |
| start `N1→N2` | current `VALID_CURRENT` DISPATCH plus existing W claim/fence | `+S` only |
| continue `N2→N2` | current `VALID_CURRENT` DISPATCH plus existing W claim/fence | continuation and `+S` only |
| complete `N2→C0/N3` | current `VALID_CURRENT` DISPATCH plus existing W claim/fence | immutable output, close claim, `+S+D+F` |
| governance/revalidate `B0→N0`, `B1→N3` | newly generated current envelope | existing `+S`, no restored claim/reviewer |
| invalidation `N0/N1/N2→B0`, `N3/N4→B1` | old envelope is retained as evidence only | existing close/revoke and `+S+D+F` |

Evidence-only operations are **event-only**, `NO_STATE_CHANGE`, on existing B0 only; they never create a scheduler transition family. Preconditions: immutable B0 governance-block ledger, original actor fixture and its now-closed claim id/fence equal the ledger, and unique idempotency key. They require no current DISPATCH and no envelope authorization; a referenced envelope, if supplied by payload digest, must first be `HISTORICALLY_VALID`. Each writes an append-only event and advances no tuple generation, dispatch generation or fence. `REPORT_BLOCKED` is once/block (`WORK_BLOCK_REPORTED`, bounded payload); `RECORD_EVIDENCE` once/block/digest (`EVIDENCE_RECORDED`); `REPORT_FAILURE` once/block (`WORK_FAILURE_REPORTED`, no F0 transition); `SAFE_YIELD` once/block (`SAFE_YIELD_RECORDED`, closes no claim because governance already closed it). Payloads are exactly [the v1 schemas](../schemas/m0-3a-evidence-only-payloads.v1.schema.json). `operational_effect=false`; no retry/remediation/success/dispatch consequence follows. B1 and every unlisted tuple deny.

Persist immutable v4 envelope closure, verification results and event references in SQLite; backup/export rehash all retained closure. Remove legacy caller receipt digests, verified flags, arbitrary receipt IDs and every authorization fallback. No Data implementation or broader capability is authorized by this planning amendment.
