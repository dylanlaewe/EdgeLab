# M0.3A v5 evidence-only integration amendment

V5 preserves v3 scheduler invariants and v4 integration intent. It adopts [Envelope v2](M0.2_DECISION_EVIDENCE_ENVELOPE.v2.md) as the only R-gate interface. Replace `decision_receipt_digest` with immutable envelope reference/digest and add blobs/manifests/output/evaluation-time retention to SQLite, replay, export and backup. No caller digest/flag/ID authorizes a transition.

When governance blocks N2, `CONTINUE` and ordinary `COMPLETE` remain denied. Add only `REPORT_BLOCKED`, `RECORD_EVIDENCE`, `REPORT_FAILURE`, and `SAFE_YIELD`: each is non-operational, fence-bound, append-only, cannot produce CLOSED success or dispatch, and records historical evidence. All other v3/v4 state, lock, migration, attachment, and scope restrictions remain unchanged.
