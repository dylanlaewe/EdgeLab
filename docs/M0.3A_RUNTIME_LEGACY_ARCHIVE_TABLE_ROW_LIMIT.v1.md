## Accepted equation

For an exact `RuntimeImage` whose `table_snapshots` field is an exact built-in
tuple with exactly `len(_TABLE_SPECS)` members, the snapshot paired by strict
zip with `_TABLE_SPECS[5]` must have an exact built-in tuple `rows` field and:

```text
len(captured['table_snapshots'][5].rows) <= 1
```

The maximum is inclusive. Zero or one row is admitted by this resource check;
two or more rows adds `TABLE_ROW_LIMIT` at `/5/rows`, marks accounting
incomplete, skips row inspection, and prevents a sanitized image from being
returned. This upper bound is not a minimum, presence, singleton-exactness, or
schema-validity claim.
