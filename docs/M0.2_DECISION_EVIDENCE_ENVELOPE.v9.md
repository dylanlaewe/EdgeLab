# M0.2 Decision Evidence Envelope v9 — sole implementation authority

V9 supersedes all earlier decision-evidence planning. It adopts unchanged M0.3A v10. Frozen `decision()` is authoritative: raw DISPATCH has six fields including operation; raw DENY has exactly five fields and **omits operation**. The normalizer copies raw fields and produces normalized DENY `operation:null`; stored normalized output is compared only to recomputation.

Canonical input explicitly binds the primary task `{task_id,task_artifact_id,task_version,task_head_sha256,generation}`, scheduler state `{artifact_id,generation,claim,fence}`, and relationship `{primary_task_id,assignment_artifact_id,handoff_artifact_id,handoff_version,handoff_head_sha256,claim_fixture_id}`. Project equality requires canonical project == source-manifest project artifact == retained FILE parsed record. Dependencies accept only `dep.status == COMPLETED`, one completion evidence, and its stated head remains equal to the frozen task record's required completion reference; a changed current/head input denies historical equality.

Raw bytes are direct envelope fields: `raw_mapping`, `raw_bytes_base64`, `raw_byte_length`, `raw_sha256`, optional matching `raw_blob_id`; verifier decodes, hashes, CJ-encodes mapping, and compares replay output. Absence assertion digest is `SHA256(CJ({source_id,expected_path,inventory_id,source_class,absence_context}))`.

All replay paths use the reusable grammar: nonempty relative slash-separated segments; no absolute, `.`, `..`, empty segment, drive prefix, or URI; `resolve(sealed_root/path)` must be under sealed root. Replay env is exactly `{PYTHONHASHSEED:"0",LC_ALL:"C.UTF-8",TZ:"UTC",PYTHONIOENCODING:"utf-8"}` with no inherited values. Package IDs in import/validation manifests resolve exactly once to engine distribution package records, each retained as immutable wheel/sdist blob; transitive offline closure is fixture v3.

Git ancestry reproduces `git -C root merge-base --is-ancestor HEAD origin/main`: left must equal observed HEAD, right observed origin main, and the shim returns only the stored result. Verification reason mapping denies `NONE` for DENY/INVALID/STALE/INCOMPATIBLE; `NONE` is permitted only valid/current/matching allow.
