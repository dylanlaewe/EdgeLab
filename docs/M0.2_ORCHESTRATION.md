# M0.2 synthetic scheduler preflight

`src.edgelab.orchestration` is an offline, mock-only preflight boundary. It is
not an agent runner, task executor, network adapter, Codex invoker, plugin
loader, source connector, or capital control.

The caller may submit only a task identifier and attempt. The scheduler resolves
the task, its claim, dependencies, project state, STOP inventory, and capability
records from `orchestration/scheduler-state.json`. That state is schema-checked
and binds exact hashes for `docs/project-state.json` and every
`STOP-M0-001` record. Any added, deleted, altered, malformed, conflicting, or
non-OPEN STOP record denies dispatch.

The task schema binds a closed synthetic purpose, role, reviewer, operation,
effects, and capability-reference list. Unknown task IDs, stale attempts,
legacy caller-controlled task/writer/dependency/capability arguments, unsafe
capabilities, and any repository other than this configured checkout or a
checkout whose committed history is not reachable from `origin/main` deny.
Symlink aliases to this checkout resolve to the same identity; copied checkouts
do not. Local Git identity is only a local containment primitive and does not
establish external trust.

The sole current task performs `SYNTHETIC_ASSERT` with `REPOSITORY_READ` and
returns `MOCK_ONLY`. A dispatch decision records a deterministic decision ID but
does not execute anything. Completion and review transitions fail closed pending
the authenticated append-only evidence `FUTURE_GATE`; no route string is an
approval or a release.

The preserved `tests/test_skeptic_orchestration_v1.py` describes the replaced
caller-controlled API and is historical adverse evidence. The versioned
`tests/test_skeptic_orchestration_v2.py` verifies the hardened semantics. M0
remains blocked, `STOP-M0-001` remains OPEN, M1 is unreleased, capital is locked,
and the kill switch remains engaged.
