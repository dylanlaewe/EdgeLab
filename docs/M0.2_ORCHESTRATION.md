# M0.2 orchestration sandbox

`src.edgelab.orchestration` is an offline decision engine, not an agent executor. It reads repository state on every decision, verifies the EdgeLab root/remote/markers, applies a default-deny M0.2 action allowlist, checks the OPEN STOP, handoff freshness, dependencies, writer ownership, reviewer distinction and capability approval. It emits an auditable decision object and returns `MOCK_ONLY`; no process, network, plugin, credential, venue, data, research or capital adapter exists.

Typed work items use `orchestration-task.schema.json`; capability metadata uses `capability-registry.schema.json`. A task routes owner completion to independent review, reviewer rejection to remediation, and approval to a Director gate. Capability metadata alone can never activate code: unapproved, revoked, or executable capabilities deny.

The M0.2 allowlist is fixed in `reports/M0.2-nonoperational-orchestration-scope.v1.md`. Unknown actions deny. The sandbox is not M1 and cannot change STOP, project phase, capital, live status or the kill switch.
