# Generator-version minimum schema proof V1

## Scope

This evidence document supports exactly one declarative schema classification:
`schemas/m0-3a-verifier-dependency-closure.v1.schema.json` at
`/properties/generator_identity/properties/generator_version/minimum`.

The addressed Draft 2020-12 keyword has value `1`. At that exact pinned
location, its local declarative meaning is:

`JSON_NUMBER_VALUE >= 1 JSON_NUMBER`

The containing subschema is the object at
`/properties/generator_identity/properties/generator_version`. Its canonical,
domain-separated digest is
`c0b9a5eadd4ba5794d76f6147f0bd5dbcecc2797f72d213ea03fcf803bf3b034`.
The proof binds the complete raw schema document, root identifier, exact
RFC 6901 pointer ancestry, keyword value, and addressed V8 site identity.

## Selection rationale

The site has an edge-none ancestor path: it is reached through `properties`
but is not nested beneath `allOf`, `if`, `then`, `else`, `oneOf`, or `$defs`.
It is not described as applicator-free because `properties` is itself an
applicator. Its containing subschema has only the adjacent `type: integer`
keyword and this `minimum`. The type keyword is context only and is not
classified by this proof.

## Evidence boundary

The executable evidence test covers values below, at, and above the bound;
fractional numbers; and boolean, string, array, and object non-domain values.
It attacks site identity, pointer, bound, equation, ancestor binding, schema
digest, sibling-keyword inference, unrelated minimum-site substitution, and
source/schema namespace separation.

This proof does not establish sibling `type` behavior, requiredness or
reachability, root or `allOf` applicability, operational or current generator
version, `runtime_v2_closure._integer` behavior, generator identity or
invocation validity, dependency-closure validity, full-schema acceptance or
rejection, deployed validator conformance, public reachability, independent
acceptance, STOP clearance, release approval, execution or wagering authority,
or capital authority. It changes no runtime behavior.
