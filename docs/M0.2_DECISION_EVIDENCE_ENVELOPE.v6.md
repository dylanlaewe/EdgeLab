# M0.2 Decision Evidence Envelope v6 — sole implementation planning authority

V6 supersedes v5/v8 and all earlier adapter plans. Schema validity, content verification, and `semantic_verify_v3=PASS` are jointly required. No caller-supplied field authorizes use.

The closed canonical input has typed task/attempt, `{task_id,attempt}` intent, expected operation, assignment/handoff logical IDs plus content heads/record versions, claim fixture/state/generation/fence, typed project/STOP/dependency/capability artifact identities, one repository identity, runtime attachment, a single generation vector, inventory IDs, Git-observation ID and UTC evaluation time. `canonical_input_sha256=SHA256(CJ(bundle))`; all duplicated envelope/output/currentness fields must equal it.

Artifact, blob, source, import, validation and distribution records use the companion closed schemas. Blob IDs equal their SHA-256 content digest. FILE/ABSENT/DIRECTORY are discriminated closed variants. Cross-reference verification resolves every ID exactly once, verifies blob bytes/digests, absence/inventory compatibility, ordered rooted inventories, source-set completeness, and every engine artifact.

Raw output is the closed frozen DISPATCH or DENY union. `normalize(raw)` copies only frozen fields: DISPATCH `{decision,decision_id,task_id,reason,execution_adapter,operation}`; DENY has the same fields with `operation:null`. It rejects all unknown fields, requires `MOCK_ONLY`, requires DISPATCH operation/task and forbids DENY operational value. Stored normalized output must equal `normalize(decoded raw)`.

Replay distribution is immutable: exact Python and package identities plus retained local artifacts, import/validation manifests, sealed launcher/shims, distribution-relative working directory/search path and fixed allowlisted environment. Closure algorithm starts at `edgelab.orchestration.decision`, follows accepted static local imports and traced `validate_record` schema reads, then requires every artifact/distribution in manifests; any undeclared decision-critical dependency is INVALID. Historical replay uses only these records, preserved Git observations and time; currentness separately compares current typed bindings.

Evidence-only B0 operations preserve v7 prerequisites exactly: original actor fixture, immutable governance block, closed claim ID/fence, generation vector and idempotency key. They are event-only: no tuple/claim/fence/generation/dispatch/retry effect. `SAFE_YIELD` acknowledges the already-closed claim; `REPORT_FAILURE` is evidence only, never F0. Idempotency key is `SHA256(CJ({block_id,operation,actor_fixture,payload_sha256,envelope_sha256|null}))`; same key/payload returns the committed event, same key/different payload denies.
