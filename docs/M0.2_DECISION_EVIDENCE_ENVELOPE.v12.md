# M0.2 Decision Evidence Envelope v12 — root graph conformance authority

V12 supersedes V11. Its schema contains the whole evidence root: frozen historical input, separate currentness binding, exact source manifest, artifacts, blobs, Git observation, engine/import/validation manifests, dependency closure, raw/normalized output and self digest. Historical input excludes later M0.3A state; currentness contains that state only. Graph verification collects typed IDs, rejects duplicates/dangling/cross-type references, resolves artifacts to blobs, manifests to artifacts/packages, engine to manifests/closure, historical input to exact source membership, and raw/normalized/currentness records by their closed types. Golden fixtures and mutation probes must validate this root before review.
