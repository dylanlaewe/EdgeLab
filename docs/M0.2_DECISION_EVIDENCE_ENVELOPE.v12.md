# M0.2 Decision Evidence Envelope v12

V12 is planning authority for a future offline decision-evidence adapter. It does not
change frozen Stage 1 code, authorize execution, or alter M0.3A scheduler states.
`schema_version: 12` has one closed root schema and exactly one engine model:
`schemas/m0-2-engine-distribution.v5.schema.json`.

## Canonical record and digest rules

`CJ(x)` is UTF-8 JSON encoded with object keys sorted, separators `,` and `:`, and
no ambient serialization options. `SHA(x)` is SHA-256 hex. A `*_sha256` digest is
`SHA(CJ(record with that digest member omitted))`, except retained blobs, whose
`blob_id`, `digest`, and FILE `raw_sha256` equal `SHA(retained bytes)`. The root
`envelope_sha256` is `SHA(CJ(root without envelope_sha256))`. A verifier rejects a
mismatch; it never repairs or recomputes a persisted record in place.

The closure record uses its published `formula` and is independently recomputed from
`docs/M0.2_STAGE1_DEPENDENCY_CLOSURE.v4.json`. DIRECTORY inventory is
`SHA(CJ(members))`; ABSENT evidence is `SHA(CJ(ABSENT record without
absence_assertion_sha256))`. `raw_evidence` is retained canonical JSON bytes of the
closed Stage 1 return mapping. Normalized output is deterministically derived from
those decoded bytes: DISPATCH preserves its six fields; DENY preserves the five Stage
1 fields and adds only `operation: null`.

## Historical replay versus currentness

`historical_input`, `source_manifest`, retained FILE/DIRECTORY/ABSENT artifacts,
blobs, Git observation, engine distribution, import and validation manifests,
dependency closure, raw bytes and normalized output prove historical validity. The
source manifest is exact: its source IDs equal the direct historical records; its
inventory IDs equal historical inventory IDs; its absence IDs name only retained
ABSENT records. Git observation is recorded with typed SHA-1/SHA-256 operands, not
selected from the current checkout.

`currentness_binding` alone binds repository/runtime/attachment/task/attempt,
workflow/execution/review state, every listed generation, claim state and fence. A
currentness mismatch returns a typed stale/deny result; it cannot invalidate or
rewrite historical validity. The provenance partition in
`docs/M0.2_DECISION_EVIDENCE_PROVENANCE.v1.md` is normative.

## Offline replay boundary

Engine v5 selects CPython only by recorded implementation/version/platform/
architecture identity; it does **not** claim retained interpreter bytes. A future
implementation must deny if that exact boundary is unavailable. It must not choose
the host interpreter as a fallback. The engine binds retained launcher, clock shim,
Git shim, local source artifacts, sealed environment, replay-relative working
directory, import/validation manifests, package archives and closure. The launcher
installs the clock and Git shims before importing frozen modules. No absolute path,
URI, drive prefix, empty segment, `.`, `..`, doubled separator, host virtualenv or
network resolver is allowed.

Every local import and validation schema resolves to one FILE and one valid blob;
every external import and validator resolves to one named package archive. Package
names exactly cover the published closure package list. Engine references must equal
the singleton root manifests and closure. Thus no path convention or ambient package
can substitute for an evidence edge.

## Verification and scheduler boundary

Use `m0-2-decision-evidence-verification-result.v3.schema.json`. `ALLOW` requires
VALID historical evidence, CURRENT currentness, compatible runtime, PASS verifier,
matching generations and reason `NONE`; every other result is `DENY` with a non-NONE
reason. Wrong runtime is `INCOMPATIBLE_RUNTIME`, never a permissive compatibility
inference.

The only scheduler-facing evidence operations remain evidence-only:
`REPORT_BLOCKED`, `RECORD_EVIDENCE`, `REPORT_FAILURE`, and `SAFE_YIELD`. They may
append bounded audit/evidence events and must not dispatch work, alter task success,
clear STOPs, mutate capital, or invoke a worker. `REPORT_FAILURE` records a failed
verification and returns DENY; `SAFE_YIELD` records no execution and returns the
frozen MOCK_ONLY result. The R-gated transition table remains the accepted M0.3A
state machine; V12 contributes no new scheduler transition.
