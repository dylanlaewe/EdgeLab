# Generator invocation min-length schema proof V1

## Scope

This evidence supports exactly the Draft 2020-12 `minLength` keyword at
`schemas/m0-3a-verifier-dependency-closure.v1.schema.json` pointer
`/properties/generator_identity/properties/invocation/minLength`, site
`85e3025e297b6d908712678e0358a97de2d8d04f2ce9af152e2ea3f566185a0a`.
Its isolated local meaning is:

`UNICODE_CODE_POINT_COUNT >= 1 UNICODE_CODE_POINTS`

The proof binds the full schema bytes, root identifier, exact pointer ancestry,
addressed V8 site, and containing-subschema digest
`5789bce9561e2fea80886b8fe5436a7a73d413ac9c49dd3a6628a7a2b575d83c`.

## Local behavior

The empty string does not satisfy this isolated keyword. Strings containing
one or two Unicode code points do. An astral character and a combining mark
each count as one code point despite their different byte and grapheme
properties. Non-string instances receive no assertion from this keyword.

Because the bound is one, these empty-versus-nonempty outcomes do not
independently distinguish Unicode code-point count from byte count, grapheme
count, or another positive-length metric. The unit comes from the frozen Draft
2020-12 declarative proof profile and schema-keyword semantics, not an inference
from this boundary matrix.
