# Executable currentness contract v1

The resolver, never a caller, reads repository records for assignment/handoff/project/STOP/capability/dependency/inventory/Git fields and M0.3A SQLite runtime authority for runtime, scheduler, claim, fence and generation fields. It acquires cooperative repository/runtime locks; resolves in schema order; canonicalizes; computes `SHA256(CJ(snapshot excluding self digest))`; then rechecks generations. Missing, conflicting, or changed generations fail closed.

Comparison accepts only `HISTORICALLY_VALID` evidence plus its immutable binding and a freshly resolved snapshot. Repository/runtime ID is `INCOMPATIBLE_IF_CHANGED`; all heads, state, STOP/capability/dependency/inventory/Git and generations are `STALE_IF_CHANGED`; missing/conflict/race is `INVALID_CURRENT_STATE`. Output is deterministic sorted changed paths and ALLOW only for CURRENT. Current records never replace historical bytes. R-gated transitions require historical valid, CURRENT, compatible, DISPATCH, exact subject/claim/fence/generation; otherwise DENY. B0 evidence-only operations retain their separate rules.

## Authoritative resolver

`tools/resolve_authoritative_currentness.py` accepts only historical status/binding and a source root. It reads repository authority from `repository.json` and runtime/SQLite-model authority from `runtime.json`, verifies attachment, snapshots under the documented runtime generation read/recheck discipline, computes digest, then delegates the typed comparison. Missing/conflicting records and changed generation fail closed; caller snapshots and caller race/conflict flags are not accepted.
