# M0.3A v6 narrow decision-evidence integration amendment

V6 supersedes v5 and adopts [Envelope v3](M0.2_DECISION_EVIDENCE_ENVELOPE.v3.md). V3 scheduler invariants, Stage 1 semantics and all scope exclusions remain frozen. An R-gated operational transition requires a `VALID_CURRENT` envelope for the exact `(task,attempt,runtime,generation)` under the common lock; old receipts, flags and IDs never authorize it.

## Final transition table

| Operation | source → target | envelope | event and tuple effect |
|---|---|---|---|
| CLAIM | N0→C0 | current DISPATCH | normal v3 claim; F and S advance |
| START | C0→R0 | current DISPATCH | normal v3 start; S advances |
| CONTINUE | R0→R0 | current DISPATCH | normal v3 continue; S advances |
| COMPLETE | R0→N3 | current DISPATCH | normal v3 completion; S advances |
| REVALIDATE | R0→R0 | newly generated current envelope | replaces binding; S advances |
| REPORT_BLOCKED | B0→B0 | no R authorization | append `WORK_BLOCK_REPORTED`; S advances only |
| RECORD_EVIDENCE | B0→B0 | no R authorization | append unique immutable evidence digest; S advances only |
| REPORT_FAILURE | B0→B0 | no R authorization | append one `WORK_FAILURE_REPORTED`; S advances only |
| SAFE_YIELD | B0→B0 | no R authorization | append one `SAFE_YIELD_RECORDED`; S advances only |

The evidence rows are legal only for an immutable governance-block ledger created by the normal block path. Request includes `block_id`, the historical claim id/fence and actor; these must equal the ledger, and idempotency key is unique. `REPORT_BLOCKED`, `REPORT_FAILURE`, and `SAFE_YIELD` are once per block; `RECORD_EVIDENCE` is once per `(block,evidence_digest)`. They retain the task in B0, never create/reopen a claim, never dispatch, never close success, do not change F or D, and cannot lead to N3. B1 and every unlisted source/target/op combination deny. All events include prior/new tuple, actor, block id, historical claim/fence, typed payload and transaction timestamp; persistence is append-only.

SQLite stores v3 envelopes and their transitive immutable closure beside event rows. Export/backup includes the closure and restoration rehashes it. Remove all authorization reads of legacy `decision_receipt_digest`, `verified`, caller-supplied envelope references and fallback receipt paths. This amendment authorizes no workload identity, real worker, executor, Codex, network, plugin/MCP, external authority, sports work, paper/live activity or capital mutation.
