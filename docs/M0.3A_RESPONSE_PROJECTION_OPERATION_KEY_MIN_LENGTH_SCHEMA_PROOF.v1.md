# Response-projection operation-key min-length schema proof V1

## Scope

This evidence supports exactly the Draft 2020-12 `minLength` keyword at
`schemas/m0-3a-response-projection.v2.schema.json` pointer
`/properties/operation_key/minLength`, site
`5dce821ee45f15010f24959f58819323b0112024635aeb4ede5380e3e47c69d4`.
Its isolated local meaning is:

`UNICODE_CODE_POINT_COUNT >= 1 UNICODE_CODE_POINTS`

The proof binds the full schema bytes, root identifier, direct-root pointer
ancestry, addressed V8 site, and containing-subschema digest
`1018889ae7b09b8e99363ab04e7d8637e3bfda0ae1aabed405c2aae2e9c78a26`.

## Local behavior

The empty string fails this isolated keyword. Strings of one or two Unicode
code points satisfy it. One astral character is one code point despite
occupying multiple UTF-8 bytes. This does not count bytes or grapheme clusters.
Non-string values receive no assertion from this keyword.
