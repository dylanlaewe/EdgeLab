# Runtime-attachment min-length schema proof family V1

## Closed membership

This family contains exactly two separately evidenced Draft 2020-12
`minLength = 1` sites from the pinned runtime-attachment schema, in this fixed
order:

1. `/properties/git_common_dir_identity/minLength`, site
   `91ac8b306ad7aaabaccc9f87de0460ce6ae4aa41d7edc09ca870364eaa9ecf38`;
2. `/properties/repository_root_realpath/minLength`, site
   `b9d97c6663e8bf814f90b1e69ba3a8ea30573b0ef575709552fe9c5e20ca06ca`.

Membership is a closed allowlist, not a live query. Both properties have the
same `{type:string,minLength:1,maxLength:4096}` container and digest, but the
family binds each complete V8 record, property pointer, and ancestor sequence.
Copied-container similarity is not identity. The two sibling `maxLength`
records are explicit nonmembers, as are every frozen prior classified schema
site and all source-bound helper sites.

## Shared local equation and evidence limitation

For string instances only, each member asserts
`UNICODE_CODE_POINT_COUNT >= 1 UNICODE_CODE_POINTS`; non-strings receive no
assertion. The empty string fails and a one-code-point string passes. This
bound-1 boundary cannot independently discriminate Unicode code points from
bytes, grapheme clusters, or other positive-length metrics. The unit is
derived from the frozen Draft 2020-12 proof profile, not inferred from these
examples. Each member owns a distinct proof, rationale, and adversarial test;
family evidence is additional and does not establish cross-property evidence
independence or semantic equivalence.

## History and nonclaims

The two sites remain nonmembers of immutable V50 and were unclassified in
that version. V55 supplies separate successor evidence; it does not rewrite,
enlarge, or reinterpret V50. V55 preserves the exact V54 prefix and rebases no
historical evidence.

1..4096 validity, property presence, root required/additionalProperties
behavior, filesystem paths, realpaths, normalization, existence, symlinks,
repository containment, Git common-directory authenticity or identity,
equality or correspondence between the properties, runtime `_string`

wagering authority, or capital authority. It changes no runtime behavior.
