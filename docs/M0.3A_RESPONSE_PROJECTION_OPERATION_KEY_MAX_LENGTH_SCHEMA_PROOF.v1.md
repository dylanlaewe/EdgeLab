# Response-projection operation-key max-length schema proof V1

## Scope

This evidence supports exactly the Draft 2020-12 `maxLength` keyword at
`schemas/m0-3a-response-projection.v2.schema.json` pointer
`/properties/operation_key/maxLength`, site
`1d6cb316a9edd5dfe397fc767d6e23f7c22e93c1e1292f19cbeff98cfea96514`.
Its isolated local meaning is:

`UNICODE_CODE_POINT_COUNT <= 256 UNICODE_CODE_POINTS`

The proof binds the full schema bytes, root identifier, direct-root pointer
ancestry, addressed V8 site, and containing-subschema digest
`1018889ae7b09b8e99363ab04e7d8637e3bfda0ae1aabed405c2aae2e9c78a26`.

## Local behavior

Strings of 255 and 256 Unicode code points satisfy this keyword and 257 do
not. The empty string satisfies this isolated maximum. Astral characters are
one code point despite occupying multiple UTF-8 bytes. Combining sequences
count their component code points, not grapheme clusters. Non-string values
receive no assertion from this keyword.
