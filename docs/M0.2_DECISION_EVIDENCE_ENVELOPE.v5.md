# M0.2 Decision Evidence Envelope v5 — final planning authority

V5 supersedes every earlier adapter plan. Frozen M0.2 is unchanged. Envelope usability is `schema_valid && content_verify == PASS && semantic_verify_v2 == PASS`; no caller assertion authorizes use. `envelope_sha256` is SHA-256 of `CJ(envelope)` with **only** `envelope_sha256` omitted.

`canonical_input_bundle` is closed evidence for the historical decision: subject task/attempt; exact intent and expected operation; assignment identity/head and writer claim/generation; handoff identity/current head; project artifact; complete STOP inventory; dependency graph/head/completion evidence; capability requirements/resolution; repository identity; consumed directory inventories; historical Git observations; runtime/attachment/repository/scheduler/dispatch/task/claim-fence generations; and UTC evaluation time. `canonical_input_sha256=SHA256(CJ(canonical_input_bundle))`. Semantic verification recomputes it and requires every duplicated subject/head/generation field agree.

Historical Git observations are `{head,origin_main,origin_url,head_reachable,repository_identity}` using discriminated Git object IDs (`git-sha1` exactly 40 lowercase hex; `git-sha256` exactly 64). The isolated Git shim receives only this record and serves precisely frozen `_remote` and `_is_ancestor_of_remote_main` calls; current Git is never queried.

Artifact records are FILE `{artifact_id,source_id,path,source_class,blob_id,raw_length,raw_sha256,canonical_sha256?}`, ABSENT `{artifact_id,source_id,expected_path,inventory_id,absence_context,assertion_sha256}`, and DIRECTORY `{inventory_id,root,selection_rule,members,inventory_sha256}`. Members carry type, relative path, artifact id and raw digest. Semantic verifier requires unique IDs/paths, root containment, lexical ordering, retained-file raw digest equality, recomputed inventory digest, existing absence inventory without the absent path, and all canonical-input/engine references resolved exactly once.

The frozen distribution schema binds exact Python/distribution versions, local modules/schemas, launcher, `edgelab.data_integrity.datetime` clock shim target, Git shim, import/validation manifests, replay working directory/module path and allowed environment. Dependency closure is the accepted static import allowlist plus traced validation schema reads; every listed local item resolves to immutable FILE bytes and an undeclared local decision-critical import is `INVALID`.

Raw output is closed canonical UTF-8 JSON mapping plus strict base64 bytes, length and SHA-256. Semantic verifier decodes base64, checks CJ bytes and reproduces frozen output. DISPATCH has non-null operation and matching task; DENY has null operation and no operational value. Output never supplies attempt/head; those equal canonical input/source evidence instead.

Historical replay uses only envelope artifacts, canonical input, Git observations, frozen distribution and evaluation time. It creates an isolated process/tree, installs `FrozenDateTime` into isolated `edgelab.data_integrity.datetime` before decision invocation, and destroys the process afterward. Currentness then resolves current repository/attachment, Git, task/attempt, assignment/handoff/claim, project/STOPS/dependencies/capabilities/inventories and all bound generations under the common lock.

Verification results use closed statuses/reasons. `ALLOW` requires historical `VALID`, currentness `CURRENT`, runtime compatibility `MATCH`, verifier `PASS`, and exact-generation match; every other condition denies. Wrong runtime preserves historical validity but denies.

Evidence-only scheduler behavior is adopted unchanged from v7/v8: B0 only, event-only and no state/claim/fence/generation/dispatch effect. `SAFE_YIELD` is solely a signal because governance blocking already closed the claim. `REPORT_FAILURE` records bounded evidence and never transitions to F0. Payloads remain closed v1 schemas.
