## Validation authority and subject model

Envelope usability requires all three, in order: **(1)** JSON Schema v4 structural validity, **(2)** retained-content/digest verification, and **(3)** `semantic_verify_v1 == PASS`. A caller cannot assert any result. Schema rejects expressible impossible forms; the mandatory semantic verifier returns typed failures for every cross-field rule below. A schema-valid envelope is never authoritative alone.

The envelope subject is `{task_id,attempt,assignment_head,handoff_head}`. Frozen output subject is only its returned `task_id` (or null on an unidentifiable DENY). Semantic verification requires non-null output task id to equal envelope task id; it does **not** invent attempt or heads in frozen output. It reconstructs the canonical input bundle and requires its task/attempt and assignment/handoff source identities equal the envelope subject.

## Artifact graph and inventories

`artifacts` is the only retained-content registry. Each unique `artifact_id` is a closed `FILE`, `ABSENT`, or `DIRECTORY` record. FILE has bytes/base64/SHA-256/length; ABSENT has path, scope and an existing DIRECTORY id; DIRECTORY has one lexical member list. `source_manifest`, engine dependency manifest, schemas, helpers, launcher, clock shim and Git shim refer only to `artifact_id`; duplicate logical IDs and dangling references deny.

Semantic verifier rules are mandatory: source IDs unique; `input.source_ids` equals exactly the source-manifest IDs; every referenced artifact exists; a FILE reference points to retained FILE bytes; an ABSENT reference points to a DIRECTORY whose root contains its path and whose members do not contain it. Each directory has unique member paths, lexical UTF-8 ordering, paths below its root, FILE members linked to FILE artifacts with equal raw digest, and digest `SHA256(CJ(member list))`. Thus all handoffs parsed by frozen `_current_handoff`, all recursively parsed records, and every consumed directory are retained, not selected subsets.

## Raw outputs and conditions

The authoritative raw representation is `raw_output.mapping` plus `raw_output.canonical_bytes_base64`; bytes are exactly `CJ(mapping)`, UTF-8 canonical JSON, base64 strict-decoded, with equal length and SHA-256. Mapping object order is non-semantic; canonical key ordering produces stable bytes. No floats, duplicate JSON keys, invalid base64, noncanonical bytes, length/digest mismatch, or normalized mutation is accepted. `normalized_output` is deterministically derived from raw mapping and cannot independently authorize.

Schema conditionals enforce frozen forms: DENY has exactly five raw fields and normalized `operation:null`; DISPATCH has exactly six, non-null operation and `MOCK_ONLY` adapter. Semantic verification reruns frozen M0.2 and requires raw mapping and derived normalized output exact equality.

## Engine closure and isolated replay

`engine_manifest` contains a closed dependency manifest listing artifact IDs for `orchestration.py`, every imported local helper/package initializer, `validate.py`, `data_integrity.py`, all reached schemas/constants/canonicalization/version/repository helpers, the sealed import-validation manifest, launcher, clock shim and Git shim; it names exact Python implementation/version and all required distributions/versions. The verifier resolves every entry to immutable FILE bytes, checks the manifest’s declared closure exactly, and makes unknown/missing/mutable substitution `INVALID`.

Loader procedure: create empty replay root; materialize only resolved FILE artifacts; set `PYTHONPATH=<root>/src`, `PYTHONHASHSEED=0`, `LC_ALL=C.UTF-8`, a minimal allowlist environment, and a PATH beginning with the materialized Git shim; launch a fresh Python subprocess. No current EdgeLab directory or site module is on the module path except declared pinned distributions.

Frozen clock installation is exact: the launcher imports the isolated `edgelab.data_integrity` module, replaces its module global `datetime` (imported by frozen code via `from datetime import datetime`) with sealed `FrozenDateTime`, then imports/uses isolated `edgelab.validate` and `edgelab.orchestration`. `FrozenDateTime.now(timezone.utc)` and `.utcnow()` return one preserved UTC-aware `evaluation_time`; non-UTC/unsupported clock APIs deny. `evaluation_time` is RFC3339 with terminal `Z`, parsed only as UTC. Tests compare direct frozen execution under this same symbol replacement with replay at boundaries and repeated calls.

The PATH Git shim intercepts precisely isolated `orchestration._remote` and `_is_ancestor_of_remote_main` subprocess calls: `git -C <replay-root> remote get-url origin` returns captured remote; `git -C <replay-root> merge-base --is-ancestor HEAD origin/main` returns captured success/failure. It rejects every other command/path. No current Git observation is possible in historical replay.

## Historical, currentness, and results

`verify_historical` uses only retained artifacts/replay and yields `HISTORICALLY_VALID` or `INVALID`. `verify_currentness` runs only after it passes, under the common lock, comparing current complete authority closure and exact task/attempt/runtime/repository generations; it yields `CURRENT`, `STALE`, or `INVALID_CURRENT_STATE`. The closed verification-result schema records historical status, currentness, runtime compatibility, authorizing use, and typed reason codes. Historically valid evidence for a wrong runtime remains historical valid but has `authorizing_use:DENY`.
