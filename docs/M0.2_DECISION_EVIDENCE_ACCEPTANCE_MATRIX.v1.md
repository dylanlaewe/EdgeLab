# V6 implementation acceptance matrix

Implementation must reject: empty/unknown/dangling/duplicate artifacts; out-of-root members, absent paths present in inventory and blob mismatches; intent/operation/attempt/assignment/handoff/runtime-generation/repository mismatches; invalid/mislabeled Git identities; invalid raw shape, DENY operation, DISPATCH null operation, base64/length/digest/normalized mutation; empty/missing/dangling/undeclared engine dependencies and mutable environment paths; INVALID/STALE/wrong-runtime/generation-mismatch ALLOW results and contradictory reasons; missing actor/claim/fence, idempotent replay/conflict and all B0 operations with no mutation/reopen.

Equivalence covers representative DISPATCH plus STOP, capability, dependency, assignment, malformed action and handoff/inventory DENYs. Historical replay must work with contradictory/unavailable current Git; current contradiction becomes STALE only.

V7 additionally rejects missing project/STOP/dependency/capability bindings, empty/unknown/mismatched blobs, unresolved/duplicate/mismatched Git observations, missing/dangling engine distributions/manifests/shims, mutable replay paths, missing package artifacts, DIRECTORY OTHER members, every derived digest mismatch and envelope self-digest mismatch.
