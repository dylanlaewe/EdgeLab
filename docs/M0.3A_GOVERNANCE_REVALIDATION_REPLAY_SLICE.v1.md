# M0.3A governance and revalidation replay slice v1

## Scope

This private slice extends runtime-v2 NEW-image replay through exact
`GOVERNANCE_BLOCK` and `REVALIDATE` transaction groups. It adds both event
types to the closed single-task follow-up dispatcher and shares their state
derivation with the immutable transition kernel and atomic transition
workspace. It adds no positive public-verifier result and no operational,
STOP-clearance, execution, or capital authority.

## Governance block

`GOVERNANCE_BLOCK` is the only task operation permitted to consume an exact
stale task state. The request and event still bind current runtime metadata,
while the before-state reference identifies the retained stale task and the
derived after state adopts the current repository generation.

Legal source states are `N0`, `N1`, `N2`, `N3`, and `N4`. `N0`/`N1`/`N2`
become `B0`; `N3`/`N4` become `B1`. Every branch advances scheduler and
dispatch generations plus task fence, clears active claim and reviewer
assignment, and preserves the prior decision receipt. An active `N1`/`N2`
claim closes as `GOVERNANCE_INVALIDATED`; an active `N4` review closes as
`GOVERNANCE_REVOKED`, using the governance semantic event as the close event.

Task, claim, and review writes form one revision-bound workspace delta.
Retained claim/review event identities are checked before commit so a stale,
forged, foreign, duplicate, or partially valid plan cannot close auxiliary
history without its task transition.

## Revalidation

`REVALIDATE` accepts only current `B0` or `B1`. It derives `B0 -> N0` or
`B1 -> N3`, advances only scheduler generation, keeps dispatch generation,
task fence, continuation count, attempt, owner, and links unchanged, and never
restores a claim or review assignment. The after-state repository generation
equals current metadata and its decision receipt equals the request's exact
`evidence_sha256`.

Both operations remain same-attempt task events. They advance the retained
task sequence and exact semantic predecessor without opening an attempt or
rewriting its origin or predecessor.

## Assurance and residual boundary

Whole-image tests cover reachable `N0 -> B0 -> N0`,
`N1 -> B0 -> N0 -> CLAIM`, and `N3 -> B1 -> N3` paths, exact receipt
replacement, claim invalidation, cumulative history, wrong source states,
malformed and alternate receipts, and candidate-table tampering. Workspace
tests cover atomic `N4` review revocation and the sole stale-task exception.

`N4` is not yet reachable in whole-image replay because review assignment is
not compiled, and stale task replay is not yet reachable there because
repository import is not compiled. Those branches are shared-kernel/workspace
assurance only and must be exercised end to end by their later prerequisite
slices. `STOP-M0-3A-002` remains OPEN. Review/routing, remediation/import,
checkpoint/export, cumulative root-work, exact generated closure identity, and
the full A-J acceptance matrix remain unfinished.
