# M0.3A v9 final evidence-only amendment

V9 supersedes v8, preserves v3/v7 scheduler semantics and adopts Envelope v6. For every B0 evidence event, required unchanged guards are: original actor fixture; immutable B0 governance-block record; matching already-closed claim ID/fence; exact generation vector; and idempotency key. All use closed v1 payloads, optional historically-valid envelope reference, `NO_STATE_CHANGE`, `NO_STATE_CHANGE` claim/fence/generation/dispatch effects, no retry and no operational authority.

| operation | event | special rule |
|---|---|---|
| REPORT_BLOCKED | WORK_BLOCK_REPORTED | once/block |
| RECORD_EVIDENCE | EVIDENCE_RECORDED | once/block/evidence digest |
| REPORT_FAILURE | WORK_FAILURE_REPORTED | evidence only; never F0 |
| SAFE_YIELD | SAFE_YIELD_RECORDED | acknowledgement only; claim already closed |

Same idempotency key and payload returns the committed event; conflicting reuse denies.
