## Exact transformation

`code[:56] + "#sha256=" + sha256(code.encode("utf-8")).hexdigest()`

characters. Length is Python `len`, not UTF-8 byte length, while the digest is
computed from the full original UTF-8 encoding. The nested helper, comparison,
passthrough, suffix construction, digest call, truncating return and slice,
subject caller, `InitialViolation` construction, surrounding method/class, and
