# V12 historical and currentness provenance

| Field class | Location | Basis |
| --- | --- | --- |
| intent/task/assignment/handoff/project/STOPS/dependencies/capabilities/Git | historical input | Direct frozen `orchestration.decision` read or deterministic parsed-record derivation. |
