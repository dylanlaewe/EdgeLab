# M0.3A private transition-workspace slice

## Scope

This slice replaces repeated immutable whole-state reconstruction during the
currently compiled NEW-image replay with a private, in-memory transition
workspace. It covers only the operation family already admitted by the image
reducer: `INITIALIZE`, the first `CLAIM`, and `START`, `CONTINUE`, `YIELD`,
`FAIL`, `COMPLETE`, and `RECOVER` worker groups.

It does not compile re-CLAIM, `RETRY`, governance, review, routing,
remediation, repository import, checkpoint, or export groups. The public
verifier remains disconnected and deny-only.

## Two-phase transition boundary

The workspace is seeded from an already validated `ReducerState`. Each group
uses the same pure transition planner as the immutable `reduce_transition`
API, producing an immutable task/claim delta and derived after-task without
mutating retained state. Complete group grammar, supplied after-state,
response, commit payload, and typed reachability are checked against that
derived preview before commit.

Commit requires the exact staged object issued by the same non-copyable
workspace at the current monotone revision. Foreign, stale, double, forged,
shallow-copied, and deep-copied paths fail closed before task or claim writes.
Task and claim changes are applied together. A group patch also binds the
exact semantic/commit event IDs and digests before workspace mutation; the
already validated replay cursor then advances through a no-fail local update.

The workspace preserves retained event-ID uniqueness and resource bounds
incrementally. At trace end it sorts all retained maps and constructs one
ordinary `ReducerState`, invoking the complete cross-record invariant
backstop exactly once. Candidate table rows and candidate before-state blobs
remain comparison inputs only.

## Boundary

The workspace, staged plans, deltas, group patches, and replay cursor are
private, local, non-serializable implementation details. They are not added to
the module's public export list and provide no I/O, writer, selector,
currentness, acceptance, execution, or capital interface.

Passing image candidates remain `UNSUPPORTED / CLOSURE_NOT_COMPILED / DENY`.
`STOP-M0-3A-002` remains OPEN. Live remains LOCKED, the kill switch remains
ENGAGED, deployable capital remains USD 0, and no market edge has been
demonstrated.
