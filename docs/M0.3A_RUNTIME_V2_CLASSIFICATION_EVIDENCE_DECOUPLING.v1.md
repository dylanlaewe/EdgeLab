# Runtime-v2 classification evidence decoupling V1

## Scope

H-M0-169 creates Classification V46 as an architecture-only successor to
V45. It adds no classified site and changes no scientific, runtime, safety,
STOP, execution, release, or capital meaning.

V46 preserves all 39 V45 constraints, their order, semantic fields, and site
sets. The classified partition remains 71 source sites plus one schema site;
649 of the 721 discovered sites remain unclassified. Coverage remains
`INCOMPLETE` and generation remains `DENY`.

## Evidence migration

Seven source-constraint evidence modules now read the explicit V42 manifest
that owns their historical source-classification census. The first real
schema-site evidence module reads the explicit V45 manifest and schema. A
distinct V2 proof artifact preserves the V45 proof fields while carrying the
decoupled evidence module's new byte identity. The V1 proof remains immutable.

The migration permits exactly nine evidence-record identity changes at eight
paths. The finding-string module supports two separate constraints, which is
why the record and path counts differ. Every non-evidence field and every site
set remains byte-for-byte equal to its V45 predecessor value. No additional
path, reordered record, substituted coordinate, or semantic change is allowed.

Current successor census accounting lives only in
`tests/test_runtime_v2_resource_classification_current.py`. That integration
test is deliberately excluded from every constraint's `evidence_inputs` so a
future schema-proof append can update current accounting without rewriting
historical constraint evidence.

## Nonclaims

This migration does not establish complete resource coverage, schema-root
applicability, deployed validator conformance, public reachability, independent
acceptance, STOP clearance, release approval, execution authority, or capital
authority. It does not change runtime behavior.
