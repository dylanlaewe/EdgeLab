# Runtime-v2 resource discovery V8

Status: `INCOMPLETE`
Generation disposition: `DENY`

V8 is an identity-only rebase over byte-pinned V7. It preserves all 425 V7
source-bound sites and all 296 legacy schema-bound records. It adds a stable
`site_id` to copies of the schema records using the V1 five-field identity
equation and binds the resulting list with the V2 schema-site list domain.

No source site is derived: `legacy_source_bound_site_count` is 425,
`derived_binding_site_count` is zero, and the cumulative source-derived count
remains 31. The census remains 721 total records. Every discovery record is
still `UNCLASSIFIED`.

Classification V44 is a proof-contract staging successor to V43. It preserves all 38
constraint semantics and all 71 classified source site IDs, classifies zero
schema site IDs, and leaves 650 sites unclassified. Source and schema site-ID
maps are built and checked separately, schema pointers must use only valid RFC
6901 `~0` and `~1` escapes, their namespaces must be disjoint, and only then may
membership be combined. V44 permits no predecessor evidence refresh. Its
standalone declarative-keyword proof profile can validate location-scoped
schema semantics but cannot add a manifest constraint or classify a schema ID.

Classification V45 preserves every V44 semantic field and site set across its
38-constraint predecessor-aligned prefix and appends one proof for the V8 site at
`/properties/active_runtime_id/minLength` in the byte-pinned active-runtime
selector schema. The local equation is Unicode code-point count `>= 1` for a
string evaluated at that exact schema location. V45 therefore classifies 71
source sites and exactly one schema site, leaving 649 sites unclassified. It
preserves every V44 semantic field and site set. A zero-evidence-rebase append
was impossible because seven byte-pinned historical classification-test paths
and the byte-pinned V8 schema-identity test asserted the former live census.
V45 therefore enumerates exactly eight test-file identity refreshes: seven
distinct paths across exactly eight constraint evidence records, plus the
schema-identity test as a non-constraint-evidence refresh. The checker rejects
any ninth file, any other evidence change, and any semantic or site-set change.
V45 remains `INCOMPLETE` / `DENY`.
