# Git-common-dir identity max-length schema proof V1

## Scope

This evidence document supports exactly one declarative schema classification:
`schemas/m0-3a-runtime-attachment.v2.schema.json` at
`/properties/git_common_dir_identity/maxLength`.

The addressed Draft 2020-12 keyword has value `4096`. At that exact pinned
location, its local declarative meaning is:

`UNICODE_CODE_POINT_COUNT <= 4096 UNICODE_CODE_POINTS`

The containing subschema is the object at
`/properties/git_common_dir_identity`. Its canonical, domain-separated digest
is `1cb0f2473cb55b110447de322170e5050e56184fc26d1d544cb298ff202d9ac5`.
The proof binds the complete raw schema document, root identifier, exact
RFC 6901 pointer ancestry, keyword value, and addressed V8 site identity.

## Local behavior

Strings of 4095 and 4096 Unicode code points satisfy this local keyword;
4097 code points do not. The empty string satisfies `maxLength` in isolation.
Astral characters count as one Unicode code point each even though their UTF-8
encoding occupies multiple bytes. Combining sequences count their individual
code points rather than grapheme clusters. Non-string instances receive no
assertion from this keyword.

are not classified by this proof. Root-level `required` and

does not make the value a validated filesystem path or repository identity,
