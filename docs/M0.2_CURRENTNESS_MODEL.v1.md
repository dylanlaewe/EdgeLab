# M0.3A decision-evidence currentness model

A future adapter uses a closed record with `repository`, `runtime`, `attachment`,
`task_id`, `attempt`, `scheduler_state`, `assignment`, `handoff`, `claim`, `fence`,
`project`, `stops`, `dependencies`, `capabilities`, `inventories`, `git`, and
`generations`. `generations` requires repository, runtime, scheduler, dispatch,
fence, assignment, handoff and claim integers. Each identity/head is read from the
current transactional scheduler authority or its bound repository snapshot; Git is
read from the attached repository. No field is inferred from an authentic historical
capture.

A value differing from the captured authorization binding produces `STALE`; an
unavailable or wrong runtime produces `INCOMPATIBLE`; either requires v3 verification
result `DENY`. Historical replay remains VALID when only this record changes.

For dependency authorization, currentness additionally resolves the current
versioned dependency head, task status, exactly-one completion reference, parsed
completion mapping and task-content digest from the current scheduler authority.
Any mismatch is STALE/DENY while retained historical replay remains VALID.

## Dependency comparison

Current authority is the scheduler's current task map and versioned task/completion
records. Compare its dependency head, task status, single completion reference,
parsed completion mapping, dependency task SHA-256 and completion content binding to
the retained historical bindings. Any difference is `STALE` and `DENY`; historical
replay is evaluated first from immutable retained bytes and remains `VALID`.

Non-dependency currentness compares current assignment/handoff identity and head,
claim state and fence, applicable STOP and capability dispositions, Git identity,
repository/runtime/attachment identity, project state, and each listed generation to
the captured authorization binding. Any mismatch is `STALE`/`DENY`; wrong
repository/runtime/attachment is `INCOMPATIBLE`/`DENY`. These current records cannot
be substituted for immutable historical evidence.
