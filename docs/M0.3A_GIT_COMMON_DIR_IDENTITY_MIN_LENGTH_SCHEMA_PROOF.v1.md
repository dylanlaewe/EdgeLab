# Git-common-dir identity min-length schema proof V1

## Scope

This evidence supports exactly the Draft 2020-12 `minLength = 1` keyword at
`schemas/m0-3a-runtime-attachment.v2.schema.json` pointer
`/properties/git_common_dir_identity/minLength`, site
`91ac8b306ad7aaabaccc9f87de0460ce6ae4aa41d7edc09ca870364eaa9ecf38`.
For a string instance, its isolated local equation is
`UNICODE_CODE_POINT_COUNT >= 1 UNICODE_CODE_POINTS`; non-strings receive no
assertion from this keyword.

The proof binds the complete 1,527-byte schema, root identifier, exact V8
address, direct-root ancestry, property coordinate, and containing-subschema
digest `1cb0f2473cb55b110447de322170e5050e56184fc26d1d544cb298ff202d9ac5`.
The copied repository-root container has the same digest, so coordinate
identity—not container similarity—is decisive.

## Evidence boundary

The empty string fails and one-code-point strings pass. These bound-1 outcomes
cannot independently distinguish code-point count from byte count, grapheme
count, or another positive-length metric. The Unicode-code-point unit comes
from the frozen Draft 2020-12 proof profile, not inference from this small
boundary matrix.

The sibling `type` and `maxLength` keywords are context only. This proof does
not establish full 1..4096 validity, property presence, root `required` or
`additionalProperties` behavior, filesystem path or realpath semantics,
normalization, existence, symlink resolution, repository containment, Git
common-directory authenticity or identity, equality with repository root,
cross-property equivalence or independent evidence, runtime `_string`
behavior, full-schema validity, deployed-validator conformance, public
validity, independent acceptance, STOP clearance, release approval,
execution or wagering authority, or capital authority. It changes no runtime
behavior.

This site remains a nonmember of the immutable V50 operation-key family and
was unclassified in V50. That version-scoped exclusion is not a perpetual ban
on a separately evidenced successor classification. V55 neither rewrites nor
enlarges the V50 family or its evidence.
