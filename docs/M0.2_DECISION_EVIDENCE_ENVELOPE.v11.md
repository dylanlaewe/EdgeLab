# M0.2 Decision Evidence Envelope v11 — sole authority

V11 supersedes every earlier planning package. Historical canonical input contains only frozen `orchestration.decision` observations: intent; task; assignment; current handoff; project `phase/status/live_status`; complete STOP directory records; completed dependency task/completion evidence; capabilities; repository/Git observations; and evaluation time. It excludes M0.3A workflow/execution/review, dispatch generation, fence, runtime attachment and later scheduler generation.

Those fields live only in `currentness_binding`, which after historical validity compares repository/runtime/attachment; task/attempt/scheduler tuple; assignment/handoff/claim/fence; project, STOPs, dependencies, capabilities, inventories, Git, and all M0.3A generations. Historical relation predicates are task/assignment/handoff identities exactly as frozen records express; currentness adds claim/generation equality.

STOP historical equality is exact directory inventory membership, retained STOP FILE artifacts and parsed records. Capability equality binds capability id, semantic types, permissions, role, trust/approval/review/revocation and effect restrictions used by frozen code. Dependency validity is completed status with exactly one completion evidence whose `content_sha256` equals the retained dependency task bytes SHA-256.

ABSENT is closed and hashes `SHA256(CJ(absence record excluding absence_assertion_sha256))`. Source manifest exact membership is derived from historical canonical input. Directory members are lexical unique FILE references below root and inventory digest is SHA256 of canonical logical record excluding its digest. One blob ID has one record.

Root traversal is envelope→engine distribution→closure/import/validation manifests→local artifacts/packages→blobs. Interpreter model is CPython version/platform identity supplied by sealed package-backed replay environment; no host fallback/network. Raw projection is UTF8 canonical JSON with lexicographic keys/no whitespace/explicit null/standard JSON booleans and integers; replay mapping, bytes, digest and normalizer output must match. Git observation is exactly `merge-base --is-ancestor HEAD origin/main` with stored left/right/result.
