## Local behavior

The empty string and strings of 1, 511, and 512 Unicode code points satisfy
this isolated keyword; 513 code points do not. Astral characters count as one
code point despite wider UTF-8 encodings. Combining sequences count individual
code points rather than grapheme clusters. Non-string instances receive no
assertion from this keyword.
