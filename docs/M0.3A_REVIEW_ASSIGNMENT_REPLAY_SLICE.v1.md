# M0.3A review assignment replay slice v1

## Scope

This private slice compiles `ASSIGN_REVIEW` only. From current `N3`, it derives
`N4`, advances scheduler generation, creates one OPEN review row, and binds the
same generated assignment UUID across semantic payload, response generated
reference, task state, and review history. All other task fields remain exact.

The request actor must differ from the immutable task-owner label and its role
must differ from the owner-role label. These are exact-string separation
checks, not authentication or proof of organizational independence.

Assignment is staged as one task-plus-review workspace delta under existing
CAS, retained-event, resource, and freeze validation. Candidate review rows
remain comparison-only. Positive replay, actor/role self-assignment attacks,
and normal/optimized-Python coverage are required.

Review decisions and director routing remain uncompiled. The public verifier
remains disconnected and valid private candidates remain opaque
`UNSUPPORTED/CLOSURE_NOT_COMPILED/DENY`. No STOP, execution, or capital
authority changes.
